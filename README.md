#Midterm Project: Single-Page Website

This was my midterm assignment from my first semester at Algonquin College, back when I was just getting started in the program (a 2-year diploma with 4 semesters total). We had to build a simple single-page website based on a provided prototype design, using HTML and CSS. I focused on laying out the header with an overlaid title on an image, wrapping text around images in the article section, listing facts properly, and setting up a form with linked labels. Everything is structured with valid, commented code—HTML in the main file, CSS in its own folder, and images organized separately.

I tweaked the theme a bit (changed subjects, images, and colors) to make it my own, as allowed. It's a basic project, but it was a great intro to web dev fundamentals like layout, semantics, and styling.
